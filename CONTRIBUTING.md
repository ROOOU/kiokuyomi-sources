# Contribution boundary

This is a generated mirror of the public KiokuYomi catalog, not a rule-source
repository. Contributions may improve repository documentation, validation,
or CI. Do not add site rules or executable code (including JavaScript, Lua,
Swift, or plugin binaries).

Never submit credentials, cookies, access tokens, private signing keys, AES
keys, bypass material, or environment-variable files. Public package URLs,
SHA-256 values, public signing keys, and key IDs may be included only when
they are already public catalog metadata.

Catalog changes are accepted only through the upstream public collection and
the automated sync workflow. Manual edits to `all.json` or `sources.json` are
not accepted.
