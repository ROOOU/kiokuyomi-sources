# Manual import

KiokuYomi does not automatically add this catalog. To use it, explicitly open
the app's rule collection import flow and paste:

`https://rooou.github.io/kiokuyomi-sources/all.json`

If GitHub Pages is temporarily unavailable, use the raw GitHub fallback:

`https://raw.githubusercontent.com/ROOOU/kiokuyomi-sources/main/all.json`

The collection contains references to signed `.kyyrule` packages, not comic
files. Only import a collection after reviewing it yourself. Do not put an
account login, Cookie, API token, or other credential into a collection URL.
