# Notice and removal requests

This repository is a public metadata mirror. It does not host comic pages,
source implementation, account data, cookies, or credentials. The referenced
rule packages are fetched from the existing KiokuYomi distribution service.

For copyright, trademark, privacy, or removal requests, use a private security
advisory on this repository or contact the KiokuYomi maintainer through the
main project. Please state the affected catalog ID, the reason for the request,
and contact information that permits a good-faith verification of authority.

Do not send passwords, cookies, API tokens, or copyrighted works that are not
needed to identify the request.
